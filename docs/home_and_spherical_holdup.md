# 首页与等效球体积气含率

## 目标与验收

将 `C:\Fluids\HkcTracker-master` 当前的等效球体积气含率实现接入本项目。逐泡从 ROI 内掩膜面积计算等效圆直径，再求球体积之和，除以 ROI 实际面积与视野深度的乘积。二维面积占比继续独立输出。视野深度与长度标定使用同一单位，保存于气含率页面配置。

应用每次启动进入首页。首页提供气泡分析、气含率和流态安全预警三个入口，左侧导航可随时返回首页；切换页面仅导航，不启动分析或清空参数。沿用现有暖白与酒红配色，并支持中英文和键盘操作。

## 实施顺序

1. 迁入球形法的核心与工作流回归测试，确认旧实现无法通过；接入体积计算和导出。
2. 接入气含率深度输入、体积结果、单位及配置恢复，合并相关翻译。
3. 添加独立 `ui_home.py` 首页，在现有导航外壳中注册，并明确启动默认页。
4. 更新文档，运行全量测试，渲染检查中英文及 1100×720 / 1480×960 布局，运行真实模型短序列验证。

## 文件与约束

- 算法和批处理：`bubble_analyzer/gas_holdup.py`、`gas_holdup_workflow.py`。
- 界面：`gas_holdup_qt.py`、`ui_home.py`、`ui_theme.py`、`ui_theme.qss`、主控制器及翻译。
- 验证：沿用 `test/` 中的 unittest，增加首页导航和启动行为测试。
- 保留现有追踪与预警改动，复用现有 PySide6 / NumPy / OpenCV 依赖。
- 气含率数值依赖球形假设、长度标定和有效视野深度。沿用来源实现的 ROI 截断面积口径，不宣称实现三维边界积分。
- `GasHoldup` 改为体积百分比；旧面积值使用 `BubbleAreaRatio`。CSV 新增 `ViewDepth`、`BubbleVolume`、`ROIVolume` 和 `VolumeUnit`。
