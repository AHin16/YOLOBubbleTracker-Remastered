# 气泡追踪连续性优化

## 行为

默认 BoT-SORT 路径采用 `tracking/bubble_matching.py` 中的气泡关联器。它复用 BoT-SORT 的轨迹对象和 ID 生命周期，关联时结合实测中心运动、检测框宽高变化和 IoU。位置按源图像帧数预测，速度使用最近观测的平滑位移；新生轨迹无可靠速度时以位置和形状联合匹配。

本模式针对固定相机的气泡图像序列，直接在图像坐标系估计运动，不使用全画面光流做相机补偿。它不预设只能上升或不能横移；移动相机场景需另行验证。边缘处使用可见边界估计速度，并按预计截断后的可见框计算形状差异，避免气泡出画面时因框变小而重复建 ID。

高分/低分检测仍分阶段关联；低分检测用于续接已有轨迹，不用于新建 ID。只输出本帧真实匹配到检测的轨迹，不把纯预测位置当作观测或物理量样本。

`demo_yolo11.Args` 新增两个配置：

| 参数 | 默认值 | 含义 |
|---|---:|---|
| `bubble_association` | `True` | 启用气泡运动与形状关联；设为 `False` 返回原版 BoT-SORT |
| `bubble_max_lost_frames` | `3` | 从最后一次检测到当前帧的最大重连间隔，直接按源图像帧数计；超过该间隔的旧 ID 在关联前移除 |

启用 `with_reid` 时仍走原版 BoT-SORT。上述参数目前为代码配置，不增加界面控件。界面原有 Match Threshold 在气泡模式下控制联合匹配代价上限，不再只对应 IoU 融合分数；保留保存的 0.7 即可开始试用。原 `track_buffer` 的帧率缩放仅用于原版路径，气泡模式使用 `bubble_max_lost_frames`。

## 空帧、显示和统计

- 空检测帧也调用两种追踪器的更新，让位置预测和失联寿命与源图像同步。ByteTrack 同时支持张量、NumPy 空数组和 `None`。
- 当前帧检测得到的目标均可绘制掩膜、ID 和有效轨迹片段；未成熟或靠近边缘时不再将整个目标隐藏。
- 边缘、成熟度和转角筛选仍限制运动 CSV 样本。未形成可靠统计样本时，画面仅标注 ID，不把缺失速度显示为 `0.00`。
- 超过转角阈值时，当前样本不进入统计，轨迹从当前点重新分段。先前有效 CSV 行保留；后续重新达到成熟条件即可恢复，避免一次异常使整个 ID 永久失效。
- 短暂无检测时不画虚构目标；恢复同 ID 后可连接历史轨迹。长间隔或异常转角会重置当前运动片段。

## 数据验证

数据：`E:\pe5\H1.2\Q0.7\2_files`，2,581 张 1264×1016 TIFF。

基准：检查时保存的 `3000.pt`、置信度 0.3、NMS IoU 0.45、BoT-SORT、Match Threshold 0.7、172.1 fps、2 帧成熟、4 px 边缘筛选、4 帧历史间隔。优化前后使用同一检测与轮廓缓存。

| 指标 | 优化前 | 优化后 |
|---|---:|---:|
| 追踪器更新帧数 | 2,272 | 2,581 |
| 画面内部 Tracked→Lost 事件 | 265 | 46 |
| 新建 ID 数 | 2,363 | 1,014 |
| 每个 ID 的观测数中位数 | 1 | 3 |
| 转角失效观测 | 92 | 5 |
| 导出运动 CSV 行数 | 924 | 1,768 |
| 前六帧三颗人工核对气泡的身份切换 | 10 | 0 |

内部失联事件指丢失前检测框距图像四边均超过 30 px 的轨迹状态变化，并非完整人工标注的真实断轨数。未成熟和边缘观测现在也绘图，因此绘图数量增加不能单独证明追踪精度提高。新建 ID 数和统计样本数同样不能当作真实气泡数或精度。

另用 `3900.pt` 同段缓存检查：内部失联事件从 144 降至 35。两模型检测量不同，不能用该指标直接比较模型好坏。完整序列仍缺逐气泡人工 ID 真值，因此没有声称达到某个 IDF1/MOTA 或消除所有串 ID。

## 验证方法

在 `hkc` 环境中运行：

```powershell
python -m unittest discover -s test -p 'test_*.py'
```

新增测试覆盖两种追踪器空帧推进、ByteTrack 空帧重连、重叠高速目标的形状身份、短时漏检、旧 ID 超时、出边缘的连续 ID、原版路径兼容、转角分段恢复、保留历史样本、绘图与 CSV 筛选分离，以及缺失速度标签。

实际模型整段推理、视频写出、轨迹 TXT 和运动 CSV 另作端到端验证。优化不会变更模型权重、气含率算法、预警流程、界面布局或用户保存参数。
